🔧 Marcar Usuário como Admin

Use esta página para marcar um usuário como administrador. Você precisa estar logado no Firebase.

📋 Instruções Alternativas

  1. Acesse o Firebase Console
  2. Vá em Firestore Database
  3. Abra a coleção users
  4. Encontre o documento do usuário (pelo UID ou email)
  5. Adicione o campo isAdmin com valor true (boolean)
  6. Salve o documento
