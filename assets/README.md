# Assets Directory

Este diretório deve conter os seguintes arquivos de imagem:

## Arquivos necessários:

1. **icon.png** (1024x1024px)
   - Ícone principal do aplicativo
   - Usado como ícone do app em todas as plataformas

2. **splash-icon.png** (1284x2778px recomendado)
   - Imagem da tela de splash
   - Exibida durante o carregamento inicial

3. **adaptive-icon.png** (1024x1024px)
   - Ícone adaptativo para Android
   - Deve ter fundo transparente

4. **favicon.png** (48x48px)
   - Favicon para versão web

## Como adicionar:

1. Crie ou obtenha as imagens nos tamanhos especificados
2. Coloque os arquivos neste diretório (`assets/`)
3. Atualize o `app.json` com os caminhos corretos se necessário

## Nota:

O app funciona sem esses arquivos, mas eles são recomendados para uma melhor experiência do usuário e para publicação nas lojas.
